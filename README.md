# Geekay E-Bike Project

This project documents my plan to convert a regular bicycle into an electric bicycle using the Geekay 36V 250W BLDC hub motor kit.

## Goals

- Understand the components needed for the conversion.
- Check compatibility with my bicycle.
- Track parts, costs, and progress.
- Document the build and testing process.

## Project Status

Currently planned the things required and waiting for the hardware
