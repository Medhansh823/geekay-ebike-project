## Confirm with the seller or technician

- [ ] Correct wheel size and spoke/rim compatibility
- [ ] Axle dimensions, dropout fit, and secure wheel retention
- [ ] Frame/fork and brake compatibility
- [ ] Adequate braking for the converted bicycle
- [ ] Correct controller, motor, display/throttle, PAS, and connector compatibility
- [ ] Battery mounting position and secure retention
- [ ] Battery/charger documentation and safety certification
- [ ] Wiring protection and weather exposure
- [ ] Lights, reflectors, and horn requirements
- [ ] Local e-bike rules and road-use eligibility

**Do not assume compatibility from wheel size alone.** Record the technician's findings and any required changes before proceeding.
